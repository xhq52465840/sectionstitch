About SectionStitch: scope, limits and licenses

A small free static conversion utility

SectionStitch turns a static page, or one section of it, into Shopify theme sections you can edit. A long page is split into parts. It does not execute submitted JavaScript, fetch a live URL, or call a paid model. Products, the cart, and checkout are not included. Literal arrays and local helpers can be resolved; runtime data, state, and unknown components are warned about or omitted.

What remains your responsibility

Missing CSS, live product data, cart/checkout behavior, theme app compatibility, accessibility, translations and actual theme-editor integration require testing. A generated schema is not proof of successful installation. Test on a duplicate theme and run Theme Check separately; the website itself does not run Shopify Theme Check in your browser.

Examples and rights

The first three examples use adapted MIT TailGrids React code. Hero navigation/client logos were removed to limit scope; the FAQ helper can be normalized to native details with an explicit warning; the features grid keeps static SVG icons. Read the original MIT notice. The pricing, testimonial-layout and image/text examples are illustrative samples created for this tool. They are not testimonials, customers or revenue claims. Only convert material you own or are licensed to reuse.

Third-party tooling and source notices

What the preview is

The converter can show an approximate preview and edit schema defaults before you download. That preview is not your theme, not Shopify’s image CDN, and not Theme Check. Dark-mode Tailwind variants are dropped so the light styles remain. There is no checkout and no paid review service on this site. We do not claim to outperform other migration tools or to reproduce a whole React application.
