Tailwind to Liquid: scoped CSS without a Tailwind CDN

Preserve supported Tailwind layouts in Shopify Liquid using compiled, section-scoped CSS; understand class-map limits, colors and breakpoints.

Updated November 6, 2026 · Static conversion, not whole-store migration

Liquid does not interpret Tailwind utility classes

A class such as md:grid-cols-3 only changes layout if its CSS exists. Loading a Tailwind CDN into a storefront can add runtime work and affect unrelated theme elements. This tool instead bundles a precompiled map of common utility rules and includes only matching rules in the downloaded section. It adds a unique section-id scope so that utilities do not become global storefront CSS. There is no runtime Tailwind CDN or paid compilation API.

Read missing-class warnings, not just the screenshot

The map covers common spacing, typography, grid, flex, colors, responsive utilities and classes used by the supplied demos. It is not the full Tailwind compiler. Simple safe arbitrary lengths and colors have a small deterministic fallback; plugins, custom tokens and complicated arbitrary selectors may still have no rule. Unknown classes are retained and listed. Add their authored CSS under the same section scope or replace them with supported utilities. A class name retained in HTML is not proof its style was converted.

Scope every selector, including breakpoints

The feature demo uses separate mobile and desktop layouts. In a standalone theme section the prefix belongs inside each media rule, not just around the HTML. Keep the section id dynamic; hard-coded IDs collide when a merchant adds two copies.

<style>
#shopify-section-{{ section.id }} .feature-grid { display: grid; gap: 1.5rem; }
@media (min-width: 768px) {
  #shopify-section-{{ section.id }} .feature-grid { grid-template-columns: repeat(3, minmax(0, 1fr)); }
}
</style>

Make color and typography checks explicit

Supported compiled RGB colors can be exposed as schema color settings. The converter caps automatic color controls rather than creating an unmanageable sidebar. Decorative SVG fills and custom CSS may still need manual controls. Compare desktop and narrow screens, long edited headings, blank images and two instances in one page. The local demos use a light layout and system fonts; do not assume your theme font, dark mode or custom Tailwind configuration will match automatically.
