How to add a custom Liquid section to Shopify safely

Install a .liquid section in a duplicate Online Store 2.0 theme, add its preset in the editor and check images, blocks and mobile behavior.

Updated November 6, 2026 · Static conversion, not whole-store migration

Duplicate your theme before touching code

In Shopify admin, open Online Store → Themes. Duplicate the theme you want to test and work on that unpublished copy. Labels in Shopify admin can change, so look for the theme actions menu and the code editor. Keep a backup of any file you plan to replace. A newly downloaded .liquid section does not need to overwrite a built-in hero or a paid theme file.

Create one file inside sections

Open the duplicate theme’s code editor. Add a new file under sections, for example sectionstitch-hero.liquid. Use a unique lowercase filename with hyphens. Paste the entire export including its style element and exactly one schema block. Save it. If Shopify rejects the JSON, read the error instead of deleting schema fields until it saves. Settings IDs, block types and preset references must match.

sections/
  sectionstitch-hero.liquid   # new file, not a replacement

# The export must contain exactly one schema block:
{% schema %}
{"name":"Custom hero","settings":[],"presets":[{"name":"Custom hero"}]}
{% endschema %}

Add the section through the theme editor

Open Customize for the duplicate theme and choose a compatible page template. Click Add section and locate the schema preset name. If it does not appear, check that the file is in sections rather than snippets, that the schema includes presets, and that enabled_on/disabled_on restrictions allow that template. Do not paste section source into a Custom Liquid block and expect it to register a new schema.

Check the edit workflow, then publish deliberately

Choose each image, set the link destinations and change the heading to something longer. For blocks, add an item, edit its title, reorder it and delete one. Preview desktop and phone widths; check keyboard focus, FAQ toggling, contrast and image alt text. Run Shopify CLI theme check on a local copy when available. Theme Check is linting, not a Shopify approval badge. Only publish the duplicate after the real storefront behavior is correct, and keep the previous theme as a rollback option.
