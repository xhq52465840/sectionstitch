Convert a React component to a Shopify section: a static-only workflow

Learn which JSX and TSX patterns can become Shopify sections, how literal map arrays become blocks, and what React state cannot migrate.

Updated November 6, 2026 · Static conversion, not whole-store migration

React behavior and Liquid rendering are not interchangeable

A React component can use state, effects, event handlers, imported components and client-side requests. A Liquid section is rendered by Shopify and configured by a JSON schema. Copying JSX into a .liquid file does not execute React. SectionStitch parses JSX as data without evaluating JavaScript, resolves supported literals, then writes markup and editable settings. Unresolved expressions and unsupported event behavior generate warnings; they are not secretly running on a server.

Use literal arrays for predictable repetition

A simple array of objects and a direct .map() callback are supported. The parser expands known values without eval; matching repeated markup can then become editor blocks. Array values from an API, a hook or a runtime prop cannot be inferred. Resolve those to sample content or build a real Shopify data integration separately. A type annotation in a TSX component is not the hard part; runtime behavior is.

const plans = [{ title: "Starter", price: "$9" }, { title: "Studio", price: "$29" }];
export default function Pricing() {
  return <div className="grid md:grid-cols-2 gap-6">
    {plans.map(plan => <article className="p-6 rounded-xl bg-white">
      <h3>{plan.title}</h3><p>{plan.price}</p>
    </article>)}
  </div>;
}

Inspect the generated structure

Text is escaped into settings. Similar article or card siblings may become repeatable blocks with a preset for each original item. The detection is a shape heuristic, not semantic understanding: decorative columns can look repetitive too. If it groups the wrong elements, simplify the input or edit the schema and loop manually. Include block.shopify_attributes so Shopify can identify the selected block.

<h2>{{ section.settings.heading | escape }}</h2>
<div class="features">
  {% for block in section.blocks %}
    <article {{ block.shopify_attributes }}>
      <h3>{{ block.settings.title | escape }}</h3>
      <p>{{ block.settings.body | escape }}</p>
    </article>
  {% endfor %}
</div>

Know when to stop using a static converter

Do not use this path for a React dashboard, cart drawer, variant picker or account screen. A converted button cannot retain an onClick handler. Imported UI libraries and unknown custom components require flattening first. Treat generated output as a starting point, run Theme Check separately, and test inside a duplicate real theme before publishing.
