HTML to Shopify section: map copy, images, links and repeated cards

Convert a static HTML fragment into an editable Shopify section with image pickers, safe text settings, link controls and optional repeated blocks.

Updated November 6, 2026 · Static conversion, not whole-store migration

Use a fragment, not a downloaded whole website

Paste one semantic section you have permission to reuse. Include its headings, paragraphs, images and links. Do not paste an entire document with external scripts, app forms, tracking pixels or copied paid-theme code. The parser removes executable and unsupported elements, but removal is not an alternate implementation of their behavior. External CSS, web fonts and remote assets do not arrive just because they were linked in the source.

Understand the field mapping

Non-empty text nodes become text or textarea settings, rendered with the escape filter. Anchor destinations become URL controls. Similar repeated article, details or card structures can become blocks. Images become image_picker fields plus alt-text settings. An image_picker cannot contain an arbitrary remote URL as its schema default, so choose/upload the image in Shopify after installing the section. The image-text sample demonstrates this limitation rather than hiding it.

{% if section.settings.image != blank %}
  {{ section.settings.image | image_url: width: 1600
    | image_tag: widths: '320, 640, 960, 1600', sizes: '100vw',
      loading: 'lazy', alt: section.settings.image_alt }}
{% else %}
  {{ 'image' | placeholder_svg_tag }}
{% endif %}

A small input is easier to verify

This HTML shape has a heading, image, paragraph and link. It avoids forms and JavaScript. Keep the heading level appropriate for its placement; an interior page section usually should not add another main page heading.

<section class="grid md:grid-cols-2 gap-8 p-8">
  <img src="/product.jpg" alt="Product detail" class="rounded-xl w-full">
  <div>
    <h2 class="text-3xl font-bold">Designed for daily use</h2>
    <p class="mt-4">Replace this with your own benefit statement.</p>
    <a href="/collections/all" class="inline-block mt-6">Explore products</a>
  </div>
</section>

Treat URL and asset warnings as work to do

A hash-only anchor, unsafe scheme or unresolved JavaScript URL is not a usable storefront link. Pick a valid destination in the editor and confirm it in preview. Test the empty-image placeholder, image aspect ratio, long copy and mobile stacking. The converter runs locally in your browser and does not upload the pasted section. Hosting still serves ordinary static assets; do not put secrets into source code in the first place.
