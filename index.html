Before you convert

Is the converter free?

Yes. Static conversion and .liquid downloads are free. There is no paid API, account or payment step.

Does my code leave the browser?

Conversion runs locally. We do not upload pasted source, store it in a database or send it to an AI model. Your browser downloads the tool and example files from our static host.

Can it migrate a whole Lovable or v0 store?

No. It handles supported static markup from one section. React state, cart behavior, products, checkout and imported packages are not migrated.

Will every Tailwind class work?

No. A bundled class map covers common utilities and the supplied demos. Unsupported classes are listed so you can add scoped CSS or simplify the input.
