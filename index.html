Before you convert

Is the converter free?

Yes. Static conversion and .liquid downloads are free. There is no paid API, account or payment step.

Does my code leave the browser?

Conversion runs locally. We do not upload pasted source, store it in a database or send it to an AI model. Your browser downloads the tool and example files from our static host.

Can it migrate a whole Lovable or v0 store?

No. A static page can become several theme sections. Products, the cart, checkout, and anything that changes when someone clicks are not migrated.

Will every Tailwind class work?

No. A bundled class map covers common utilities and the supplied demos. Unsupported classes are listed so you can add scoped CSS or simplify the input.

Can I preview the section before installing it?

Yes. After conversion you get an approximate preview and the text, link and block fields. It is not your theme, not Shopify’s image CDN and not Theme Check. Install the file on a duplicate theme and select images there.

Install it on a duplicate theme

Download the .liquid file, paste it under Sections, then select images in the theme editor. This site does not take payment or review your code.
