Privacy: browser-only source processing

Your pasted source is processed locally

The converter parses code inside your browser. We do not send pasted HTML or JSX to a conversion server, AI model, payment processor or account database. No analytics script or ad code is included. Source is not saved unless you opt in to a local draft, described below.

What the network still does

Your browser downloads the site, parser and optional example files from Cloudflare Pages. The hosting provider can process ordinary request metadata such as IP address and user agent. Browser-only conversion does not mean your visit creates no network requests.

Keep secrets out of markup

Do not paste API keys, customer records or credentials. The tool never needs a Shopify password or store admin access. Images referenced in source are not fetched for a conversion preview: output uses image pickers that you configure inside Shopify.

Optional draft on this device

If you check “Keep this paste on this device”, the source and section name are stored in localStorage in this browser until you uncheck the box or clear site data. The draft is not uploaded. Leave the box unchecked and nothing is written.

No account and no paid intake

There is no account, waitlist, file-submission form or paid service on this site, and no public contact inbox is configured.
